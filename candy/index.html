Candy Crisis for the ZX Spectrum Next

A port of John Stiles's falling-blob puzzle game Candy Crisis to the ZX Spectrum Next, playing by the original's rules. The game's program has the title, the tutorial and the first three levels; the rest of the levels, the pictures and the music are in a data file, candy.dat, which goes in the same folder on the SD card as the game.

You do not need to fetch it by hand: with a WiFi module set up on your Next, the game offers to download it when you reach the end of the demo, and from the Data File row of its Settings page. This page is for anyone without WiFi in the game, or who prefers to copy the file over themselves.

Source

The port's source code (GPL version 2) is at github.com/bitbymonster/candy-crisis-zxspectrum-next.
